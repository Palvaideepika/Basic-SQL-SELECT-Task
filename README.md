# Basic SQL SELECT Task

## Overview

This project demonstrates basic SQL queries using MySQL. It covers retrieving, filtering, and sorting employee records.

## Topics Covered

* SELECT
* WHERE
* ORDER BY
* BETWEEN

## Database

* Database: `basic_sql`
* Table: `employees`
* Records: 10 employees

## Files

* `Basic_SQL_Select_Task.sql` — SQL queries for the task.
* Screenshots — Query execution results.

## Tools Used

* MySQL Server
* MySQL Workbench
